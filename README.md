# ⚡ BCG X - Data Science & Analytics Job Simulation: SME Customer Churn Analysis

## 📌 Project Overview
This repository contains the complete work for the **BCG X Data Science Job Simulation**, focusing on predicting customer churn for **PowerCo**. Every task from problem framing to final executive presentation is structured in sequential order below.

---

## 🗂️ Task Sequence & Repository Structure
| Task # | File Name | Description |
| :---: | :--- | :--- |
| **1** | **`Task 1 - Understanding business & frame problem.pdf`** | Initial commercial and strategic problem framing, outlining hypotheses and project scope. |
| **2** | **`Task 2 - EDA & Data Cleaning.ipynb`** | Exploratory Data Analysis, handling missing values, data type corrections, and distribution checks. |
| **3** | **`Task 3 - feature_engineering.ipynb`** | Advanced feature engineering, including historical price sensitivity differentials and customer tenure metrics. |
| **4** | **`Task 4 - modeling.ipynb`** | Training and evaluation of a **Random Forest Classifier**, handling class imbalance, and feature importance analysis. |
| **5** | **`Task 5 - BCG X SME Churn Analysis Executive Summary.pdf`** | Final executive presentation summarizing technical findings and commercial recommendations for client stakeholders. |
